# ADR 009 · Delegar en un proveedor de pagos

Fecha: 2020-10-31

## Estado

Propuesto

## Contexto

El _sistema de órdenes_ debe aceptar una amplia variedad de métodos de pago para satisfacer las expectativas de los usuarios y agrandar la base de usuarios. La cantidad de sistemas de pago es significativa y cada uno tiene matices en la API y en las formas de comunicación.

## Decisión

Usar un proveedor de pagos de terceros para delegar el trato con los distintos sistemas de pago.

## Consecuencias

Ahorramos el tiempo requerido para implementar sistemas de pago grandes, pero hay que seguir las tendencias y pagar comisiones por procesar transacciones.

El sistema de pagos interno igual debe dejar espacio para implementar adaptadores adicionales para sistemas de pago emergentes.

Riesgos: Hay que tener cuidado al procesar los detalles personales/demográficos del usuario, en cuanto a cumplimiento y auditoría.
