# Glosario

## Usuarios

- **Usuario ocasional** - usuario sin cuenta. Paga en efectivo en el punto de venta.
- **Usuario conocido** - usuario con cuenta y tarjeta asociada, pero sin suscripción a un plan de comidas.
- **Suscriptor** - usuario con cuenta, suscripto a la entrega regular de comida.
- **Administrador de PoS** - trabajador del punto de venta (PoS) que crea transacciones para los _usuarios ocasionales_.

## Sistemas

- **Sistema de órdenes** - sistema objetivo a diseñar y desarrollar. Responsable de las interacciones con todo tipo de usuarios.
- **Sistema de gestión de kioscos** - sistema responsable de comunicarse con las heladeras inteligentes y gestionar sus artículos de stock.
- **Ghost Kitchen** - sistema responsable de la ejecución de órdenes y la reposición de comida. https://en.wikipedia.org/wiki/Ghost_kitchen
- **App de usuario** - aplicación web o móvil para los usuarios. Front-end del _sistema de órdenes_.

## Términos

- **Actualización de inventario** - información para una Ghost Kitchen sobre las comidas requeridas.
