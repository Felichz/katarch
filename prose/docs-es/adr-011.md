# ADR 011 · Cada entrega lleva un código PIN de retiro

Fecha: 2020-10-28

## Contexto

La conexión de red puede perderse cuando una comida se entrega en la heladera y un usuario viene a retirarla. Entonces la heladera no puede verificar online los datos del usuario por tarjeta deslizada, o por apertura remota desde la app.

Pero la heladera tiene un teclado de PIN y todavía cuenta con un software bastante sofisticado y memoria interna para procesar órdenes.

Actualización 2020-11-24:

Esperamos que cada comida tenga su propio id único provisto por la cocina, porque algunas comidas pueden estar personalizadas respecto del catálogo general. Digamos que una lasaña sin lactosa debe ir dirigida a un usuario específico.

Entonces, en el proceso de compra o producción, podemos actualizar el dispositivo del usuario con el id único de la comida y generar un código de acceso basado en el id de la comida.

## Decisión

Las comidas despachadas desde una Ghost Kitchen llevarán un código especial de 6 a 8 dígitos.

## Consecuencias

Ahora el usuario puede retirar su comida incluso si la heladera inteligente está desconectada de la red al momento del retiro.

Los códigos PIN de las comidas deben formarse por adelantado y entregarse temprano a los dispositivos (heladera inteligente y dispositivo del usuario). Posiblemente haya un mecanismo para actualizar esos códigos con la entrega de la comida preparada. El código PIN debe ser bastante largo para reducir la probabilidad de un ataque de fuerza bruta.

**Función extra:** es más fácil delegar el retiro de la comida a otras personas.

**Riesgos:** Alguien puede tener la suerte de adivinar un código PIN al primer intento.

**Argumentos:** ¡los códigos de 8 dígitos son demasiado largos para tipear!
