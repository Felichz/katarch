# ADR 003 · Sistema de trazado y monitoreo

Fecha: 2020-10-29

## Estado

Propuesto

## Contexto

Este es un sistema de crecimiento rápido y el escalado just-in-time es esencial. También permite comprar instancias más baratas para los servicios sin degradación general.

El monitoreo adecuado y confiable es la base para tomar cualquier decisión sobre cambios de infraestructura (escalado y extracción de servicios); un buen monitoreo debe sostener decisiones de negocio y funcionar como función de aptitud arquitectónica.

Queremos usar un sistema que nos dé el cuadro completo de eventos de negocio correlacionados, servicios conectados y cantidad de recursos consumidos.

## Alternativas

#### DataDog

DataDog es un servicio de monitoreo para aplicaciones a escala de nube que permite monitorear servidores, bases de datos, herramientas y servicios mediante una plataforma SaaS.

La plataforma DataDog permite visualizar métricas en un dashboard y provee alertas. La solución se puede integrar con Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform, Red Hat OpenShift, etc. El costo de DataDog como solución de monitoreo es **15 USD por host, por mes**.

#### Graphana

Grafana es una solución open source para ejecutar analítica de datos, levantar métricas con sentido a partir de grandes volúmenes de datos y monitorear tus apps con dashboards personalizables. Grafana se conecta con cualquier base de datos posible: Graphite, Prometheus, Influx DB, ElasticSearch, MySQL, PostgreSQL, etc. La solución es gratuita.

#### ELK Stack

"ELK" es el acrónimo de tres proyectos open source: Elasticsearch, Logstash y Kibana. Elasticsearch es un motor de búsqueda y analítica. Permite agregar logs, buscar sobre ellos y visualizarlos. Al ser un proyecto open source, no hay costos financieros asociados a comprar el stack.

#### Amazon CloudWatch

Amazon CloudWatch es la herramienta de alertas de AWS para enviar notificaciones basadas en los niveles de severidad de las métricas inspeccionadas. Costo aproximado: 0,30 USD por las primeras 10.000 métricas.

## Decisión

Aunque ELK stack o Graphana son las opciones más baratas para FoodFarmacy, decidimos elegir DataDog porque requiere una integración mínima sin mantenimiento (al contrario de ELK Stack o Graphana). La conveniencia de una herramienta todo en uno de alertas y monitoreo por 15 USD al mes es demasiado difícil de discutir. Finalmente, eligiendo una solución open source tendríamos que asignar entre 0,2 y 0,5 del tiempo de un desarrollador / administrador para ocuparse del monitoreo.

## Consecuencias

Vamos a tener que gastar 15 USD y el precio podría subir en el futuro. Pensamos que es poco probable que sea un aumento significativo. Menor carga de mantenimiento por ser DataDog un servicio gestionado.
