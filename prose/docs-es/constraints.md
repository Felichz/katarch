# Restricciones

A continuación se listan las restricciones globales de la solución que gobiernan todas las decisiones de compensación:

1. El equipo de desarrollo es limitado, así que la solución debe ser simple al comienzo para probar las ideas de negocio
2. El tiempo de salida al mercado es crítico y, junto con la restricción anterior, el despliegue debe ser súper simple
3. AWS es la plataforma objetivo primaria de despliegue
4. El presupuesto es muy limitado, así que el software libre (OSS) y las herramientas provistas por la plataforma objetivo deben quedar arriba en la priorización
